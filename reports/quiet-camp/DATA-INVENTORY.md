## Intended schema versus implemented schema

None of these proposed names was found as an emitted custom Analytics event: `game_started`, `game_session_started`, `game_session_ended`, `level_start`, `level_complete`, `level_fail`, `level_restart`, `checkpoint_reached`, `game_progress_saved`, `settings_changed`, `tutorial_begin`, `tutorial_complete`, `rewarded_ad_requested`, `rewarded_ad_completed`, `reward_granted`, `interstitial_ad_shown`. The six `qc_*` records above are the implemented schema. Domain events and debug logs are not automatically Analytics events. Firebase automatic events require an actual installed/enabled SDK and are separate.

ComfortAnalytics limits events to 120 per session; counts saturate at 250. Width/height clamp 4–8, preset 0–3, value band 0–10. Frame bands are ≤18/≤35/≤50/>50 ms and quality 0–2. Duration bands are <30s/<1m/<2m/<5m/<10m/longer. Summaries can be emitted on completion, leaving and backgrounding. SDK metadata remains pseudonymous personal data; the source comment “aggregate” does not establish anonymization.
