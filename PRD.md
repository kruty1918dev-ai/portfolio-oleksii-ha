# Developer website: purpose and structure

The website is a permanent home for Oleksiy Havryliuk's independent games and
selected portfolio projects. Kruty1918 Games is a personal trading name.

The primary visitor paths are:

- Home → Games → a specific game → screenshots, original guide and legal document.
- Home → Portfolio → a project → contribution/context and original public resources.
- Any page → About → portrait, biography and contact channels.
- A Google Play or app link → the unchanged Quiet Camp privacy route → game/developer.

The site must support new games on the same domain without a new frontend stack.
Every project receives a unique, directly accessible URL. Shared page generation,
nav, footer, language alternates and sitemap must keep navigation consistent.

All primary content is static HTML in Ukrainian, English and German. Native
mobile navigation and language links work without JavaScript. The optional local
image viewer supports keyboard navigation, Escape and focus restoration. Images
must be genuine project captures, with provenance and honest development status.

Use a warm-paper editorial frame for the developer pages and individual game
identities: forest/field-book for Quiet Camp, dark cartographic for Moyva,
sky/portrait captures for Fun and Ball. Shared spacing, navigation and controls
connect them. System text fonts avoid external font requests. Content,
project imagery and readability take priority over decorations or skill badges.

The portrait belongs to developer context. No relocation plans, training/job
application copy, age, telephone number, residential address or CV download is
part of the new public site. Country-level biography is retained. Project pages
must distinguish solo work from collaborative prototypes and store releases from
work in development. Never add imaginary release dates, testimonials, numbers,
store buttons or future games as though they exist.

Quiet Camp's existing policy keeps its fixed public route and complete legal
content. Its review qualifications remain visible. A missing legal postal address,
unknown latest Firebase installation and unresolved underage handling are not
solved by a redesign.

A separate /privacy route covers website delivery and correspondence in all
three languages. Its unresolved legal-address/hosting/mail facts remain explicit.
