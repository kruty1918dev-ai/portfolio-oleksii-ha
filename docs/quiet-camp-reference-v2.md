# Quiet Camp · композиція сайту V2

22.10.2026. V2 замінює відхилену композицію V1.

Орієнтир: https://pouncelight.games/tiny-glade/ . Перевірено поточні HTML, CSS і фонове зображення офіційного сайту. Визначальні риси: один кадр світу на весь viewport, незайнята ліва частина сцени, логотип і кілька рядків тексту поверх правої частини, кілька простих посилань. На вузькому екрані вміст центрується поверх того самого світу. Окремої картинки поруч з однотонною колонкою немає.

У V2:

- Сцена Quiet Camp заповнює перший екран від краю до краю. Повернення до розробника й мови лежать поверх сцени.
- Власний wordmark Quiet Camp, коротке речення, чесний статус розробки й три посилання лежать поверх правої частини кадру; окремої панелі немає.
- На телефоні логотип і текст центруються поверх зображення. Контент може збільшити висоту першого екрана за великого масштабу тексту.
- Два додаткові кадри розташовані нижче без карток, рамок, нумерації та довгих підписів; збережено співвідношення сторін. Завершує сторінку компактний футер.
- Структура й графіка інших 30 HTML-сторінок не змінені. Нові стилі обмежені класами quiet-*; юридичні сторінки й поточні API збережено.
