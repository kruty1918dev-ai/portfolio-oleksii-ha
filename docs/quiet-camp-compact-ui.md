## Перевірка перед native-прийманням

Підготовлені PlayMode сценарії оновлено для прямої навігації налаштувань і нових Boot IDs. Вони тут не виконувалися й не є доказом native-компіляції. Старий tools/menu_device_qa.py описує історичне меню категорій і не є командою приймання цього кандидата.

Потрібен авторизований native запуск: усі стани таблиці, safe area, портрет / ландшафт, 320–1440 px, усі три мови, 130% текст, клавіатура / фокус / утримання значків, переривання Boot, помилка запису, повторний запуск, відмова й відкликання, UMP та відсутні SDK. Перевірити, що friend badges не перекривають дії, item icons читаються, а зменшений dock зручний для drag. Roslyn syntax scan не перевіряє Unity-типи чи layout.
